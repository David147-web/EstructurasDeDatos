Estructuras de Datos
====================

Repositorio con ejercicios y prácticas de la asignatura de Estructuras de Datos.

Contenido principal
- ED Practica 2/: ejemplos y código Java de la práctica 2
- Practica1/: ejercicios de la práctica 1
- Ejercicio 2/, Ejercicio 3/, Ejercicio 4/, Ejercicio 5/: otros ejercicios
- Gestion Notas ED/: proyecto de gestión de notas

Cómo usar
1. Clona el repositorio:
   git clone https://github.com/David147-web/EstructurasDeDatos.git
2. Entra en la carpeta del proyecto que quieras y compila/ejecuta según sea Java u otros archivos.
